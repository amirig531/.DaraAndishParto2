# اپ کاتالوگ آفلاین دارا اندیش پرتو

این پروژه نمونه اولیه اندرویدی است. رابط کاربری در فایل `app/src/main/assets/index.html` و اطلاعات نمونه در آرایه `products` قرار دارد.

## ساخت APK بدون Android Studio
1. یک Repository در GitHub بسازید و این پروژه را در آن آپلود کنید.
2. از تب Actions، workflow با نام Build Android APK را اجرا کنید.
3. پس از اتمام، Artifact به نام `DaraAndishParto-APK` را دانلود کنید.
4. داخل آن `app-debug.apk` قرار دارد؛ آن را به گوشی منتقل و نصب کنید.

## قبل از انتشار
- نمونه محصولات داخل برنامه صرفاً دمو هستند؛ جایگزین داده‌های واقعی شوند.
- شماره تماس در صفحه درباره شرکت را وارد کنید.
- لوگو در `app/src/main/assets/logo.png` قرار دارد.
- پروژه در نسخه فعلی به اینترنت، حساب کاربری یا سرور وابسته نیست.
